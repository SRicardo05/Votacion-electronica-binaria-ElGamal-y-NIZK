# Votacion-electronica-binaria-ElGamal-y-NIZK
una votación de aula con un máximo de veinte participantes. Los votos se cifrarán con ElGamal exponencial, se acompañarán de pruebas no interactivas de que contienen 0 o 1 y se sumarán sin descifrar cada voto. Los tokens de un solo uso controlan quién puede votar y el expediente publicado permite auditar lo que aceptó la urna.
